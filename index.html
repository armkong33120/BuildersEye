Overview

ระบบนี้คืออะไร? (What is BuildersEye)

เครื่องมือวิเคราะห์ HR และโครงสร้างองค์กรยุคใหม่ รวม 3 เทคโนโลยีหลักเข้าด้วยกัน

🧠

1. RAG เหนือ Org-Graph

ค้นหาข้อมูลโปรไฟล์, KPI, defect, OKR จาก Excel 160 ไฟล์ ผ่านภาษาธรรมชาติ (ไทย/อังกฤษ) ตอบแม่นยำ ไร้ hallucination ด้วย AlaSQL + Hybrid Index

🌐

2. 3D Visualization Tree

แสดงโครงสร้างองค์กร 150 คน เป็นพีระมิด 3D 4 ชั้น (CEO → C-Level → Manager → Staff) Node กระพริบทันทีเมื่อถูกอ้างอิงในคำตอบ AI

🛡️

3. Role-Based Access (RBAC)

ควบคุมสิทธิ์ข้อมูลเข้มงวด 4 ระดับ (CEO / HR / Manager / Employee) บล็อกคำถามข้ามสิทธิ์ เช่น พนักงานถามเงินเดือน CEO ในระดับ Governance Layer

ใครได้ประโยชน์จาก BuildersEye?

กลุ่มผู้ใช้งาน บทบาทหลัก สิ่งที่ได้รับจากระบบ
CEO ผู้บริหารสูงสุด (Managing Director) เห็นภาพรวม KPI/OKR องค์กร, ความเสี่ยง Retention, วางแผน Succession Planning
HR ฝ่ายทรัพยากรบุคคล (HR Manager) ค้นหาโปรไฟล์ 360°, ประวัติผลงาน/Defects, วางแผนอัตรากำลังคนรวดเร็ว 10x
Manager ผู้จัดการทีม (IT/COO/CFO Manager) ติดตาม Project Backlog, ประเมินผลงานทีมในสายบังคับบัญชา (Subtree)
Employee พนักงานทั่วไป (Staff Member) ตรวจสอบ OKR/KPI ตัวเอง, ประวัติงาน และข้อควรปรับปรุงส่วนบุคคล

Architecture

สถาปัตยกรรมระบบ (System Flow & Brain Selector)

แผนผังแสดงเส้นทางการประมวลผลข้อมูลจาก User Query สู่การกรอง RBAC และเลือกสมอง LLM

Tech Stack

เทคโนโลยีที่ใช้ (Technology Architecture)

คัดสรรเครื่องมือประสิทธิภาพสูง ตอบโจทย์ความเร็ว ความปลอดภัย และความคุ้มค่า

🎨

Frontend

  • Vite (Multi-page build)
  • Vanilla JS (ES Modules)
  • Three.js (3D Org Graph)
  • Modular Modern CSS3
⚙️

Backend & Security

  • Node.js & Express REST API
  • JWT (jsonwebtoken + bcryptjs)
  • Policy Gate (4 Roles RBAC)
  • PII Anonymizer Engine
📊

Data & RAG Engine

  • AlaSQL (In-Memory SQL)
  • Excel Parser (xlsx node)
  • Vector Embedding Index
  • 160 HR OneDrive Datasets
🤖

AI & Infrastructure

  • OpenAI-compatible client
  • DeepSeek V3 / Ollama
  • Vercel (Frontend Hosting)
  • Render (Backend Hosting)
Roadmap

คุณค่าต่อยอด & Flywheel การพัฒนา

ยกระดับประสิทธิภาพต่อเนื่องผ่านกลไก Self-Improvement Flywheel

ตารางมูลค่าการพัฒนาต่อยอด (Compounding Value)

ระยะพัฒนา ฟีเจอร์ที่ได้ มูลค่าต่อองค์กร
ปัจจุบัน (M1-M2) RAG + 3D Org Graph + Governance RBAC ค้นหาข้อมูลรวดเร็วขึ้น 10x
ระยะถัดไป (+ Auth) ระบบ Login จริง 150 บัญชี + RBAC Strict ป้องกันข้อมูลรั่วไหล 100%
+ Fine-tune (QLoRA) เทรน Model เฉพาะบริบท HR ภาษาไทย ลดค่าใช้จ่าย API สถิติติดต่อกัน
+ Realtime Sync ซิงค์ไฟล์ OneDrive/Excel รายวันอัตโนมัติ ข้อมูลอัปเดตเป็นปัจจุบันเสมอ
+ Analytics Dashboard กราฟเทรนด์ OKR, Attrition & Succession Risk ตัดสินใจเชิงกลยุทธ์แม่นยำ
